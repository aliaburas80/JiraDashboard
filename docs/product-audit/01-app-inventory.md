# Delivery Clarity — Application Inventory (Checkpoint 1)

**Scope:** All 64 `app/**/page.tsx` routes as of commit `de490f4` (2026-07-12). API routes (72) are counted in `00-audit-control.md` but not individually inventoried here — deferred to Checkpoint 5.

**Evidence basis:** Every row below is built from direct code inspection (either by the lead auditor, who authored/maintained the 18 `/dashboard/*` routes and the `/summary`/`/help`/`/developer`/`/glossary` routes across the preceding work session, or by three delegated research passes that read each remaining `page.tsx` file plus its immediately-obvious primary data source). **No rendered/visual verification was performed for any route** — no browser-automation tool is available in this environment (see `00-audit-control.md` §4). Every "Initial concern" below is a factual, code-grounded observation, not a Keep/Merge/Remove recommendation — those are explicitly out of scope until Checkpoint 4.

**Confidence labels used below:** `[Code-confirmed]` = read directly by the auditor or a delegated pass. `[Cross-referenced]` = confirmed by comparing two independent sources (e.g. a service name matched in two files). Where a concern names a *suspected* duplicate that wasn't directly diffed against its counterpart, this is stated explicitly rather than implied.

## Cross-cutting findings (not tied to a single route)

These emerged from Checkpoint 1's environment/framework discovery and route-comparison work. They are recorded here as evidence for Checkpoint 4/5/9, **not** acted on now.

1. **Three non-Next.js, git-tracked code trees live in the repo and are unreferenced by the live app**: `frontend/` (standalone CRA, 15 tracked files, already tracked as `ORPHAN-01`), `backend/` (standalone Express API, 12 tracked files, **newly discovered this checkpoint**, not previously tracked anywhere), `promotion/` (marketing assets, 8 tracked files). None are referenced by `render.yaml`/`docker-compose.yml`/`Dockerfile`, none are imported by `app/` or `src/`. [Code-confirmed — `git ls-files`, repo-wide grep, deployment config inspection.]
2. **A git-tracked, stale duplicate file**: `app/profile/page 2.tsx` (187 lines, dated © 2025) has been committed since early project history (`git log --follow` traced to commit `ffb2c04`). Inert for Next.js routing (wrong filename), but sits in the public repository. [Code-confirmed.]
3. **A second orphaned "legacy dashboard view" component family, related to but not identical to the already-tracked `ORPHAN-02`**: `DashboardViewSelector.tsx` and the `defaultDashboardViewForRole()`/`allowedDashboardViewsForRole()`/`isDashboardViewLockedForRole()` functions in `src/lib/roles.ts` have exactly one caller (`DashboardViewSelector.tsx` itself), which is not mounted anywhere in `app/`. [Code-confirmed via repo-wide grep.]
