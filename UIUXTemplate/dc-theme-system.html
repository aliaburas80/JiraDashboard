Motion tokens
Consistent easing and timing across all themes and pages.

Hover — 150ms

transition: background, transform, color
easing: cubic-bezier(0.22,1,0.36,1)
use: buttons, nav links, table rows

Standard UI — 220ms

transition: opacity, transform
easing: cubic-bezier(0.22,1,0.36,1)
use: modals, dropdowns, panels, drawers

Scroll reveal — 360ms

opacity: 0 → 1 / translateY: 20px → 0
stagger: 60–100ms per card
trigger: IntersectionObserver 10%

Chart — 800ms

gauge: strokeDashoffset 0 → score
KPI count-up: 0 → final value
line chart: left-to-right path draw

Nav active pill — 200ms

background slides horizontally
absolute positioned pill element
translateX to active item position

Profile menu — 200ms

opacity: 0→1 / scale: 0.95→1
transformOrigin: top right
cubic-bezier(0.22,1,0.36,1)

Page load sequence

1. Nav fades in: 0ms
2. Hero content: 100ms delay
3. KPI cards stagger: 60ms each
4. Charts draw after cards settle

Reduced motion

@media(prefers-reduced-motion: reduce)
all durations → 0ms
no translateY offsets
opacity transitions only
